# Project Agent Instructions

## Dev cycle

### Issue tracker

Issues, specs, and tickets live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Issue labels

Use the issue states `needs-grilling` and `ready-for-agent`, plus the fixed category labels `bug` and `enhancement`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
